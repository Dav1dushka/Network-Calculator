# Network Calculator

A browser-based IPv4 network calculator built with HTML, CSS and JavaScript.

The project focuses on practical networking concepts such as IPv4 addressing, CIDR prefixes, network addresses and broadcast addresses.

## Features

- IPv4 address validation
- CIDR prefix selection
- Network address calculation
- Broadcast address calculation
- Address capacity calculation
- Client-side validation and calculation
- Responsive browser-based interface

## How It Works

The application converts the IPv4 address to a 32-bit value, applies the selected CIDR network mask and derives the network and broadcast addresses.
